# 서버 명세

`momens-server`의 **서버 레벨 명세**를 두는 곳입니다. 서버의 책임 경계, 도메인 모델,
API 계약을 다룹니다.

## 범위

- **여기 두는 것**: 서버 명세 — 서버 책임/경계, 도메인 모델, API 명세, 영속성/통합 규칙.
- **여기 두지 않는 것**: 제품 레벨 문서(PRD·ADR·용어집·product language). 이는
  [`teams`](https://github.com/Momens-Works/teams)가 단일 출처이며, 여기서는 복제하지
  않고 링크/참조합니다.
