# 0003. Flyway 마이그레이션 순차 버전 채택

- 상태: Accepted
- 날짜: 2026-06-23

## 맥락

Flyway 버전 스킴은 순차(`V1`, `V2`)와 타임스탬프(`V20260623…`) 두 가지가 흔하다. 순차는
교과서 기본이고 읽기 쉽지만, 병렬 브랜치에서 같은 버전 번호 충돌이 날 수 있다.

## 결정

순차 버전을 사용한다: `V<n>__<snake_case 설명>.sql`.

## 대안

- 타임스탬프 버전: 충돌이 없지만 길고 가독성이 떨어진다. 큰 팀·잦은 병렬에 적합.

## 결과

- 좋음: 읽기 쉽고 교과서적. 2인 규모에서 충돌이 드물다.
- 감수: 같은 번호 충돌 시 번호를 올려 해결. 추후 팀이 커지면 타임스탬프로 전환 가능
  (타임스탬프가 더 큰 수라 기존 순차 뒤에 자연 정렬되어 기존 파일은 안 건드림).
